# Python 3.10–3.12 (pinned; see pyproject.toml's requires-python) —
# pip install -r requirements.txt
#
# This is the core install: the Streamlit UI, the LangGraph orchestrator, the
# text-only ingestion path, and both LLM backends. Layout detection (detectron2
# + VLM figure captions) is optional and lives in requirements-layout.txt.
#
# Pins refreshed 2026-10-14. Verified: the full test suite passes on Python 3.12
# with exactly these versions, the real openai / langgraph / lxml / PyMuPDF
# libraries were driven through the repo's own code paths, and the set resolves
# to binary wheels on Python 3.10, 3.11 and 3.12 (Linux x86_64 and macOS arm64).
#
# numpy is held at 2.2.x on purpose: numpy 2.3 needs Python 3.11 and 2.5 needs
# 3.12, so a newer pin would silently drop the 3.10/3.11 support declared above.
#
# Python 3.13: the old blocker (lxml 4.9.4 had no cp313 wheel) is gone, but
# pyproject.toml still caps requires-python at <3.13 and these pins have not
# been run on 3.13, so the cap stays until they are.
#
# chromadb: a newer chromadb can migrate the schema of an existing store when
# it opens it, and an older one may then refuse that store. Back up the persistent
# disk (or test on a copy) before running a new image against a populated store.
