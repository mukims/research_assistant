# Minimal dependencies to run the test suite.
#
#   python -m pip install -r requirements-test.txt
#   CITATION_LOG_FILE=0 python -m unittest discover -s . -p "test_*.py"
#
# The suite exercises pure logic — citation parsing, paper naming, extractor
# filing, ingestion bookkeeping, retrieval ranking. The heavy stack (ChromaDB,
# PyTorch, detectron2, layoutparser, the LangChain embedding chain) is imported
# lazily inside the functions the tests never call, so none of it is needed
# here. That is deliberate: it keeps the tests runnable anywhere.
#
# No provider SDK (ollama, openai) is needed here: every agent now calls
# research_assistant.shared.llm.chat()/chat_stream(), and test_llm.py exercises
# the ollama/openai backends by injecting fakes into sys.modules rather than
# importing the real packages.
numpy~=2.2.6
requests~=2.32
